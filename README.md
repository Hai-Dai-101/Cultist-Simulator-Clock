# 密教模拟器 · 钟面

一面钟的网页。二十四时辰环绕，圆心是「入梦」；点任一司辰，看他的牌面与判词；
从攀登向上，走五道门；残页、教团、探索，最后是十三种准则与各自的结局。

单文件页面（`index.html`）+ 同目录 `assets/`，无构建、无依赖、无外部请求。

## 内容来源

- 司辰名录与牌面据《司晨》整理
- 准则符号与释义据《性向》
- 门与攀升据《攀升》
- 教团据《教团》
- 敌人与地点据《敌人》《地点》
- 仪式判词与残页散句为本站编订

《密教模拟器》（Cultist Simulator）为 Weather Factory 作品，本页为非商业同人展示。

## 本地预览

直接双击 `index.html` 即可。

## 部署

推送到 GitHub，仓库根目录保持 `index.html` 与 `assets/` 同级，然后在
Settings → Pages 里把 Source 设为 `main` 分支的 `/ (root)`。
